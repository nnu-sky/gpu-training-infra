# 批量与训练成本评估

仅在用户关心批量、显存、吞吐或训练成本时读取。批量变化可能改变更新次数、随机性、归一化和训练轨迹，应与保持原批量的纯工程优化分开说明。

## 轻量测量

1. 固定模型、数据、精度、增强、GPU 数量和其他主要设置。
2. 从当前批量开始测试少量合理候选；显存不足、吞吐不再改善或稳定性出现问题时停止。
3. 排除明显的冷启动后测量短稳定窗口。窗口长短根据项目单步时间、编译和动态形状调整，不使用统一步数。
4. 观察吞吐、峰值显存、单轮更新次数，以及尾批、周期边界和编译是否会抵消固定步收益。

把“吞吐拐点”理解为继续增加批量后收益已经很小的较小合理批量，而不是能够填满显存的最大批量。

## 粗略估算

设训练样本数为 `N`、批量为 `B`、稳定吞吐为 `Q`、训练周期数为 `E`：

```text
每周期更新次数 = ceil(N / B)
训练计算段周期时间约为 N / Q
训练计算段总时间约为 E × N / Q
完整时间还应考虑启动、周期性任务、保存和必要评价
```

只有短窗口数据时，使用大致范围，不给出伪精确的完整训练结论。

## 结果说明

简要比较：

- 当前批量与候选批量；
- 吞吐和峰值显存；
- 每周期更新次数变化；
- 预计时间范围；
- 训练配方和目标指标可能受到的影响。

保持当前批量作为工程基线。候选批量虽然更快，但如果可能影响最终结果，应作为独立训练配方，而不是静默替换原设置。
